01

Resumind

Built

Resumind lets job seekers check a resume against a target job description and get practical feedback to improve it.

What it does

  • Accepts resume uploads in supported document formats
  • Compares resume content with a job description
  • Shows keyword matches and missing terms
  • Gives structured feedback on content and presentation

Built with

A React frontend and a Python FastAPI backend, connected through REST API endpoints. I tested and debugged it, then deployed it for public access.

Note: Resumind supports editing. It does not guarantee ATS results or interviews.

Solo project, in development
